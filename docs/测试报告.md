## 6. 遗留问题与适配限制

1. **P1 功能未实现**（后端尚无接口，前端为占位并给出友好提示）：本体 CRUD、图谱邻居展开、最短路径、布局切换、知识库设置、分段清洗预览、文档删除（级联）、关系检索、修改资料/密码、节点搜索定位。上述项**不可测**，待实现后补充用例。
2. **P2 内容学习模块**：按 PRD 不纳入硬性验收，未实现。
3. **大文件解析**：本次仅验证小文件；≤20MB 的解析耗时未实测（建议后续补一个 1–2MB 文档计时）。
4. **环境依赖**：中文 Windows 下若直接执行 `alembic`，`alembic.ini` 编码问题会导致迁移失败（已在其他分支处理，本报告环境使用 `create_all` 不受影响）。

## 7. 优化建议

1. 抽取实体含 `建议`、`学生`、`效率` 等泛化词，建议在领域词表/停用词中补充过滤，或调整 `MIN_ENTITY_FREQ`（属后端二）。
2. Markdown 解析保留了 `#` 标题符号，建议清洗后再分段。
3. 文档详情「实体数/关系数」建议给出“本文档新增”与“本文档关联”的清晰区分（配合 BUG-002）。
4. 建议为前端补充自动化 E2E 用例（如 Playwright），降低手工回归成本。

- P0 核心闭环**全部通过**，系统可正常运行与演示。
- 发现 2 个 Bug（1 中 1 低），均不影响核心闭环演示，建议在验收前修复。
- 建议修复 BUG-001、BUG-002 后执行**回归测试**（重点：全新环境部署、文档详情概览），并补充 P1 实现后的用例。
