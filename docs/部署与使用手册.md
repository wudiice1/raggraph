# 部署与使用手册 —— 认知知识库系统

本手册面向部署者与使用者，图文步骤说明环境安装、项目启动、默认账号及核心功能操作全流程。

## 1. 系统简介

认知知识库系统：上传文档（PDF/DOCX/TXT/MD）→ 自动解析分段 → jieba 抽取实体与关系 → 知识图谱可视化（ECharts）→ 关键词检索。技术栈：后端 FastAPI + SQLAlchemy + SQLite + jieba；前端 Vue3(CDN) + ECharts。

## 2. 环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows / macOS / Linux |
| Python | 3.10 及以上 |
| 数据库 | 无需安装（SQLite 单文件，首次启动自动创建 `backend/knowledge.db`） |
| 前端 | 无需构建（Vue3 走 CDN），只需一个静态文件服务器 |
| 网络 | 前端首次加载依赖 CDN（Vue3 / 字体），需联网 |

## 3. 后端部署与启动

```powershell
# 进入后端目录
cd E:\heart\oceanai8.3.2\raggraph_1\backend

# 1) 创建虚拟环境（首次）
python -m venv .venv

# 2) 安装依赖
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# 3) 【重要】补装缺失依赖（见“常见问题” BUG-001）
.\.venv\Scripts\python.exe -m pip install chardet

# 4) 启动服务
.\.venv\Scripts\python.exe run.py
```

启动成功后终端显示 `Uvicorn running on http://127.0.0.1:8000`。
- 接口文档（Swagger）：`http://127.0.0.1:8000/docs`
- 首次启动会自动建表并写入种子数据（默认实体/关系类型 + 内置 admin 账号）。

> 注意：本项目后台解析为自管线程模型，**仅支持单进程运行**（`python run.py`），请勿使用 `uvicorn --workers N`（N>1）。

## 4. 前端部署与启动

前端为静态页面，用任意静态服务器托管即可（示例用 Python 自带模块）：

```powershell
cd E:\heart\oceanai8.3.2\raggraph_1\frontend
..\backend\.venv\Scripts\python.exe -m http.server 5173
```

- 前端地址：`http://localhost:5173/index.html`
- 后端地址配置：前端 `assets/js/config.js` 中的 `apiBase`（默认 `http://127.0.0.1:8000/api/v1`）。若后端部署在别的地址/端口，改这里即可。

## 6. 使用指南

1. **注册 / 登录**：打开 `http://localhost:5173/index.html`，输入用户名/邮箱/密码注册，或直接登录。
2. **上传文档**：进入「文档库」→ 上传（支持拖拽、多选）→ 选择 PDF/DOCX/TXT/MD（单文件 ≤20MB）。
3. **查看解析状态**：列表中的状态标签依次为 `待解析 → 解析中 → 已完成`（失败会显示错误信息，可点「重新解析」）。
4. **查看知识图谱**：进入「知识图谱」页，可见节点（按实体类型着色）与关系连线；支持缩放、拖拽、悬浮提示；点击节点弹出详情（类型、关联关系、证据句、来源）。
5. **知识检索**：进入「知识检索」页，输入关键词 → 全文检索返回命中文档/分段并高亮，实体检索返回匹配实体及关联信息。
6. **退出**：点击退出登录，返回登录页。

## 7. 常见问题（FAQ）

**Q1：`python run.py` 报 `ModuleNotFoundError: No module named 'chardet'`**
- 原因：`requirements.txt` 未列 `chardet`，但解析模块使用它（BUG-001）。
- 处理：执行 `.\.venv\Scripts\python.exe -m pip install chardet`；建议开发同学把它补进 `requirements.txt`。

**Q2：端口被占用（8000 / 5173）**
```powershell
# 查看占用并结束对应进程
Get-NetTCPConnection -LocalPort 8000,5173 -ErrorAction SilentlyContinue |
  ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
```

**Q3：上传扫描件/图片 PDF 后状态为「失败」**
- 属预期：无文字层的扫描件无法提取文本，会提示「未能从文档中提取到文本（可能为扫描版 PDF 或纯图片文件）」。请上传含文字层的文档。

**Q4：Swagger `/docs` 调用受保护接口返回 401**
- 需先 `POST /auth/login` 获取 token，再点右上角 **Authorize** 填入 token（不用加 `Bearer` 前缀，若仍 401 则改为 `Bearer <token>`）。

**Q5：前端页面样式/交互异常或空白**
- 多为 CDN 未加载成功（需联网）；检查网络后刷新。

## 8. 停止服务

在运行服务的终端按 `Ctrl+C`；或按 Q2 的命令结束对应端口进程。
